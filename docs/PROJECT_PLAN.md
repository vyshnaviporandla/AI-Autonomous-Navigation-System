# Project plan

## Milestones
1. Environment setup and first launch.
2. Grid map and obstacles.
3. A* path planner.
4. Animated navigation.
5. Save metrics and capture proof.
6. Add tests and publish to GitHub.

## Current scope
This starter project uses a known 2D grid map. It does not yet perform camera-based perception, neural-network object detection, localization, or physical robot control.

## Success criteria
- A* returns a path from START to GOAL when one exists.
- The path never crosses blocked cells.
- The agent reaches the goal in the simulator.
- A run summary is written to `outputs/run_metrics.csv`.
- Unit tests pass with `python -m unittest discover -s tests`.
